# 📦 Dependencies

* A font patched with [Nerd Font](https://github.com/ryanoasis/nerd-fonts)

* [sketchybar-app-font](https://github.com/kvndrsslr/sketchybar-app-font) for stylised application icons

* SF Symbols (installed by `brew install --cask sf-symbols`)

* [switchaudio-osx](https://github.com/deweller/switchaudio-osx) for selecting the current audio output source

* [blueutil](https://github.com/toy/blueutil) for connecting paired Bluetooth devices

* [icalBuddy](https://hasseg.org/icalBuddy/) for listing upcoming calendar events
